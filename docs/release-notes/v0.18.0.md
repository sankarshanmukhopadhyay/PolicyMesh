# PolicyMesh v0.18.0

v0.18.0 completes the capabilities previously represented as Partial in the roadmap within their declared scope, adds explicit policy lifecycle and rollback semantics, operational trust-anchor management, safe versioned registry interchange, cryptographic algorithm governance, portable evidence bundles, and optional authority-context evidence.

The release also establishes a repository status contract, governance/security controls, deployment profiles, machine-readable assurance mappings, CI validation, and a reorganized adoption-oriented documentation architecture.

The release does **not** claim production certification, independent assurance, HSM-native custody, unconstrained gossip networking, or the legitimacy of external governance/agent mandates.
