# Governance

PolicyMesh owns its implementation semantics, schemas, tests, evidence formats and repository status declarations. It does not own the legitimacy of an external trust framework, institution, registry, principal or agent mandate supplying policy.

Normative changes to lifecycle semantics, federation behavior, cryptographic policy, schemas or evidence formats require tests and documentation. Operational delegation is bounded by village configuration, quorum rules, signer allowlists and trust anchors. Revocation and supersession preserve historical evidence.

See the repository-level `GOVERNANCE.md` in the source repository for the complete governance contract.
